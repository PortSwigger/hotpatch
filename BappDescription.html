Burp Hotpatch offers pentesters a streamlined method to hook into critical BurpSuite functions using self-written scripts. This enhancement to your toolkit allows you to alter and augment Burp Suites default functionality, creating a more customized penetration testing experience.

Features

  • Supports Javascript and Python scripting languages.
  • Includes a user-friendly script editor with syntax highlighting.
  • Allows concurrent activation of multiple scripts.
  • Facilitates easy debugging workflows.
  • Enables users to add custom actions to the context menu for quick tool execution.
  • Seamless integration with the Montoya API within Burp.
  • Inbuilt task manager to control utility execution and context menu actions.
  • Provides shared variables between scripts.

Usage

Burp Hotpatch can be used in the following scenarios:

  • Session handling actions requiring further processing after session macro execution.
  • Writing payload processors for Intruder.
  • Scenarios where Bambda expressions are inadequate.
  • Prototyping and testing.
  • Automation/integration with other tools.

Burp Hotpatch handles ContextMenuItemsProvider, HttpHandler, ProxyRequestHandler, SessionHandlingAction, and PayloadProcessor events. Upon occurrence of these events, any relevant user scripts are executed.

Users can create scripts that incorporate handlers for various Burp Suite functions or stand-alone scripts that can run interactively within Burp Suite. Potential script types include Utility, Http Handler, Proxy Handler, Session Handling Action, Payload Processor, and Context Menu Action. Due to security reasons, all scripts must be enabled whenever the extension is loaded.

Errors or exceptions in scripts highlight the script in red and provide STDERR for review. Alternatively, users can print debugging information to STDOUT. All scripts use the Montoya API to interact with Burp Suite and are executed in a GraalVM environment. Scripts can be written in either Python or JavaScript.
